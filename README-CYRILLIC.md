# ГРУ-Эйнфлусс: КИ-Инфлуенцер унд Террор-Нетцверк ин Дойчланд

## Элеватор Питч

Ди Унтерзухунг дэкт айн хох-организиртес, пан-ойропэишес Террор-Нетцверк аоф, дас КИ-генерирте Инфлуенцер унд Музикер нутцт, ум психологише Криэгсфюрунг, Финанцбетруг унд Югенд-Манипулацион цу бэтрэйбен. Гелэйтэт фом русишен Гэхэймдиэнст ГРУ, тарнен зих диэзе Операционен алс Музиг- унд Социал-Мэдиа-Индустри, мит Унтерштютцунг эхтер Рэпстарс ви Кул Савас унд Сидо. Дэр дойче Штаат эркеннт ди Гэфар нихт одер ист бэтэйлигт – мит ферхэррендэн Фолген фюр Дэмократи унд Гэзэлшафт.

### Кэрнбэфундэ
- **КИ-Инфлуенцер**: Том Рорбёк, Наоми Зэйбт, Эрик Арэнс, СИРА, Хоу2Ширли (оперэйтэд бай Йеннифэр Александра Корнау унд Ясмин Фэддэр) усв. зинд ГРУ-инструмэнтирте Фигурэн фюр политише Манипулацион унд Радикализирунг.
- **Форэнзише Штимманилисэ**: Дас БКА хат Юлиус Фалкэнхайн-Валклинг алс Урхэбэр дэр КИ-Персона "Криё Шталка" идэнтифицирт (зиэ БКА-ШТИММЭН-АНАЛИСЭ.md).
- **Финанцкриминальтэт**: Миллионэн дурх Бот-Нетцверкэ, Стрээминг-Бетруг унд Гэлдвэшэ.
- **Тэррор-Инфраструкур**: 2000+ Агэнтэн, АИ-Музикер алс Цэрзэтцунгсваффэн, "Виолэнс ас а Сэрвис".
- **Штаатлихе Комплицэншафт**: Варнунгэн зинд лэхерлих, ви Рэзэнвэрботэ – ди Бэдроунг вирт унтершэтцт.
- **Глобалэ Райхвайтэ**: ГРУ-Тэхнологи, Тэх-Сэкэн, интэрнационалэ Тэррор-Фэрбиндунгэн.

### Ауфруф цум Хандлэн
Дис Нетцверк бэдрот Ойропас Зихерхайт. Зофортигэ Унтерзухунгэн, Ойропа-вайтэ Маßнахмэн унд Ауфклерунг зинд эрфордэрлих. Ди Вахрхайт: Дэр Штаат вэрсагт, вэндэ гэшейтэртэ Индивидуэн ди Фрайхайт мисбраухен.
